你需要准备：自己的 Tiingo key

  • 行情来自 Tiingo。你需要注册一个自己的 Tiingo 账户（有免费套餐），在账户页面复制 API key。
  • 第一次打开软件时粘贴一次。软件先用它取 5 天 SPY 行情检查，通过后才存进这台 Mac 的系统钥匙串；之后打开不用再填。
  • 软件不会要你的 Tiingo 密码，也不会替你注册或登录。可以随时在软件里更换 key，或断开并删除它。

Tiingo 套餐和条款

  • 免费 Starter 套餐：每小时 50 次、每天 1000 次请求，每月 500 个不同代码；许可为“仅供内部使用”（Tiingo 价格页）。分析一家公司大约要 5 到 6 次请求。
  • 你的使用受 Tiingo 服务条款约束，不同套餐允许的用法不同，使用前请先阅读条款。

安装

  1. 下载上面的 .dmg 文件并打开。
  2. 把 Stock Agent 拖进“应用程序”文件夹。
  3. 第一次打开时，macOS 会提示这是从互联网下载的 App，点“打开”。

不需要安装 Python，也不需要运行任何命令。

你的数据去哪里

  • 没有账号系统，软件不会把你的数据发给开发者。行情、财报和利率都由你的 Mac 直接向 Tiingo、SEC 和美国财政部请求；向 SEC 请求时带着软件的联系方式（SEC 要求这样做）。
  • Tiingo key 只存在 macOS 系统钥匙串里，不写进任何文件、日志或报告。
  • 分析结果默认只在内存里，关闭软件就清除；只有你自己点“下载报告”或“打印”时才会生成文件。
  • SEC 和美国财政部的公开数据会缓存在 ~/Library/Application Support/StockAgent，下次取数更快。这个缓存里能看出你查过哪些公司、什么时候查的；不想留下这些记录，就删掉这个文件夹（软件会重新下载）。
  • 软件退出时会删掉网页组件自己留下的文件（缓存、Cookie、窗口状态）；如果软件崩溃或被强制退出，会在下次打开时删掉。

卸载

  1. 在软件首页点“断开并删除 key”，把钥匙串里的 key 删掉。（如果软件已经删了：打开“钥匙串访问”，搜索 StockAgent.Tiingo，删除那一项。）
  2. 退出软件，把 Stock Agent 从“应用程序”拖到废纸篓。
  3. 删除 ~/Library/Application Support/StockAgent 文件夹（公开数据缓存）。
  4. 如果还想清得更干净：删除 ~/Library/Preferences/io.github.dr16.stockagent.plist（窗口位置等系统偏好）。其余位置软件退出时已经清理。
